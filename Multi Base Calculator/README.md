# 🧮 Multi Base Calculator

A simple yet powerful Python CLI calculator that supports multiple number systems (Binary, Octal, Decimal, Hexadecimal) and performs basic arithmetic operations.

---

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔁 Convert between number systems:
  - Binary (base 2)
  - Octal (base 8)
  - Decimal (base 10)
  - Hexadecimal (base 16)
- ✅ Input validation
- 🎨 Colored terminal output
