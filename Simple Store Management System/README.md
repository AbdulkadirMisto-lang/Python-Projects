# 🛒 Store Management System (Python)

A simple console-based Store Management System built using Python.  
This project is designed for learning and practicing Python fundamentals.

---

## 🚀 Features

- ➕ Add new products
- 📋 Display all products
- ❌ Delete products
- 💰 Sell products and calculate total price
- 🔍 Search for products
- 💵 Track total profit
- 💾 Save and load data using JSON file

---

## 🧠 Concepts Used

This project helps to practice:

- Variables and data types
- Functions
- Lists and dictionaries
- Loops and conditions
- File handling (JSON)
- Error handling (try/except)
- Basic CRUD operations
